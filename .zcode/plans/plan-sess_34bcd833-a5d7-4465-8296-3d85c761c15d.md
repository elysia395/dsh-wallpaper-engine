## Wallpaper Engine 调节页面重构：标签页 IA + 组件视觉升级

### 目标
解决设置页与吉祥物抽屉（共用 `src/client.js` 的 `WallpaperPicker`，约 30 个控件单列长滚动）拥挤难找的问题；同时升级组件视觉品质（高级感）。功能 0 丢失，只动视图层，不改任何数据/持久化逻辑。

### 一、信息架构：6 个顶部页签（两处界面共用）

| 页签 | 内容（现有控件原样迁入） |
|---|---|
| **壁纸**（默认） | 当前壁纸卡（黑胶 + 选择壁纸 + 暂停/关闭/刷新）、自动轮播（轮播列表管理 + 自动轮转 + 间隔）、自定义壁纸（存储位置 + 上传） |
| **外观** | 配色、玻璃颜色、玻璃透明度、设置窗口液态玻璃；侧栏玻璃组（仅 `sidebarPresent`：侧栏液态玻璃 → 模糊/透明度/玻璃颜色/内容面透明度/底色，保持现有级联 gating） |
| **字体** | 字体自定义 + 颜色/字重/字体族（保持条件渲染） |
| **吉祥物** | 显示开关、形态、大小 + 新增实时预览块（复用 base64 图按 ropeScale 缩放） |
| **效果** | 模糊/亮度/对比度/饱和度/暗化/边框/玻璃滑条、适配、水平翻转、倍速、帧率、遮挡暂停、beta 场景动画；无壁纸时显示引导性空态 |
| **高级** | 紧凑布局、Edge 兼容 |

页签选中状态每处界面独立（本地 state + localStorage 记忆，不动 config.json 结构）。

### 二、组件视觉升级（保留液态玻璃身份）

**色彩纪律（最大的一项提质）**：标签/数值/提示一律改用宿主中性墨色 token（`--dsw-alias-label-*`，明暗主题均可读）；强调色 `--we-accent` 只用于：选中页签、滑条填充、开关开启态、色板选中环、chip 选中、主按钮、焦点环。终结「满屏粉红」。

**统一控件词汇**（全部 32px 高，各带 default/hover/focus-visible/active/disabled 状态）：
- **开关**：现有原生复选框全部替换为统一的胶囊开关（36×20，thumb 滑动 180ms，开启态 accent）
- **滑条**：4px 中性滑轨 + accent 填充 + 玻璃质感滑块（hover/drag 微放大），数值右对齐 tabular-nums 安静胶囊
- **页签栏**：玻璃分段式轨道 + 滑动指示器（220ms transform），16px 内联 SVG 线性图标 + 文字；窄抽屉 nowrap + overflow-x 兜底
- **色板**：22px 圆 + hairline 内环，选中 accent 外环；自定义色板用 conic 彩虹环示意
- **select/按钮**：统一 32px、自绘 chevron、hover 着色；主按钮（选择壁纸/上传）accent 着色变体
- **说明文字**：长说明收进 tooltip，行内只留一句 tertiary 短语
- **吉祥物预览卡**：玻璃面板内按 ropeScale 实时缩放渲染形态图

**动效**：页签面板 160ms 淡入 + 4px 位移、指示器滑动、开关/滑块过渡，全部 ≤250ms、ease-out；`@media (prefers-reduced-motion: reduce)` 全部退化为瞬时。
