# M 矩阵构造深挖笔记（本轮逆向）

## 定位数学最终确认（函数 0x1401EC25A-0x1401EC41F，pdata 边界）

### 官方定位 = origin(0x2f0/0x2f4) × 0.5 × M(0x344-0x37f 的 3×3)，结果写对象 0x9f0-0xa2f（完整 4×4）

- **0.5 = 常量 0x1404926c0**（movss 读取于 0x1401EC322 与 0x1401EC446，装入 xmm11/xmm0），固定场景→画布缩放。
- **两个分支殊途同归**：
  - r15b≠0（0x1401EC2AC 分支）：0x1401EC338 直接算 origin×0.5×M → 写 0x9f0/0xa00/0xa10/0xa20。
  - r15b==0（0x1401EC3F1 分支）：先算 0x9b0-0x9ef（=origin×0.5×M），再经 0x1401EC5A6-0x1401EC5E7 复制到 0x9f0/0xa00/0xa10/0xa20。分支2 还额外把 origin×0.5×矩阵B(0x384) 写 0x970。
- **M 第4行（0x374 movups）不是丢弃**：movups 0x374(%rsi),%xmm1 → 0x1401EC5E7 movups %xmm1,0xa20(%rax)，即**结果矩阵第4行 = M 第4行**。M 是完整 4×4。
- 结果 0x9f0-0xa2f 被 0x1400D9537-0x1400D95D2 复制到输出顶点矩阵数组（rdi+rdx*1，rdx=movzwl 0x2(%rsi,%r9,2)），另有 0x1400D94E6-0x1400D9514 复制 0x9dc-0x9ec（M 的一部分）。这些是"提交到渲染"路径。

### 关键理解
- **0x9f0 区域 = 对象定位后的完整 4×4 变换矩阵**（不是单个点）。
- 0x970/0x9b0 区域 = 中间矩阵（矩阵B 与 M 的 origin 缩放版本）。
- 0x9f0 第4行来自 M 第4行（0x374-0x383），若 M 含平移列则结果含平移。

## M 的构造（0x14014774B-0x140148477，pdata 边界）

- 0x14014774b 是**前函数 epilogue**（lea r11/pop/ret，链接器重排），实际主体从 0x140147782 开始（jne 0x140148445）。
- 大矩阵链乘法：r14=对象，r12+rcx*8=矩阵数组（movups 0x10/0x20/0x30/0x40/0x50/0x60/0x70(%r12,%rcx,8)，16B 步进=矩阵行），与 r14 的 0x0/0x20/0x40/0x60/0xa0/0xc0/0xe0 及 0x310-0x3f0 区域做 mulps/shufps/addps/subps 的 4×4 乘法。
- **M 写入点**（matrix340-write.mjs 已列）：0x14014810b 写 0x340、0x14014811a 写 0x360、0x1401482a5 写 0x370、0x140148296 写 0x350；0x310/0x320/0x330 及 0x390-0x3f0 是相邻矩阵区域。
- 0x140147f31 读 0x2f0(%r14)（origin）参与计算 → **M 链乘法可能含 origin 平移**。
- **无直接 call 引用**（0x140147782/0x14014774b/0x140148477 均无 E8 call），.rdata 无 vtable 指针——经 jmp 或间接进入（函数指针）。
- r12 数组基址从 r13+0x30→0x18→lea(%r12,%rcx,8) 取（0x1401482cd），rcx=骨骼索引。

## 0x384 第二矩阵（矩阵B）

- 无条件复制 0x384/0x394/0x3a4/0x3b4 → 0xa30/0xa40/0xa50/0xa60（0x1401EC26A-0x1401EC29B）。
- r15b≠0 时还复制到 0x970-0x9a0（0x1401EC2B2-0x1401EC2E3）；r15b==0 时 origin×0.5×矩阵B → 0x970（0x1401EC3F1 起）。
- 矩阵B 在 0x384-0x3c3（4×4），用途待定（可能锚点/旋转矩阵）。

## 相机矩阵区域（0x1160/0x11a0）

- 0xc8 对象 + 0x1160 与 0x11a0 = 两个 4×4 矩阵，被 movups 复制到矩阵栈（0x38/0x40 处，push 风格，0x1401EC8C2-0x1401EC993、0x1401E9836-0x1401E989E）。
- 0x1401ed0d0-0x1401edb1b 函数：读取 0x178/0x17c（两 float）与矩阵做 mulss/addss 3×3 乘法（0x1401ed27f 起），后调 0x140184f00（0x140184F00-0x140184FF8）。
- 0x14005f730 = 3×3 旋转矩阵运算（叉积/正交化），非视图应用。

## 结论（本轮）

- 官方定位**不含 -eye 视图平移**：定位数学纯 origin×0.5×M，M 为对象自身矩阵（骨骼/世界链），0.5 固定。
- DSH 的 origin×ps（ps=DSH宽/场景宽）与官方 origin×0.5 在 DSH 分辨率下等价（0.5×2=1 @3840）。
- 头错位（头 vs 发/耳/眼）可能源于 M 中的锚点/骨骼矩阵差异（puppet 697 vs 空锚 463/494），或 0x384 矩阵B 未实现。
- 0x9f0 结果矩阵被复制到输出顶点矩阵 → 顶点变换用。0x9f0 第4行 = M 第4行（可能含平移列）。

## 追加：M 完整构造链（决定性）

### M（对象 0x344-0x37f）的真正来源
- **0x1401E9609-0x1401E9636**：M = 0xc8 场景对象 + 0x8f0/0x900/0x910/0x920 复制（movups 4 行）。**0x1401E95B5-0x1401E95D6**：矩阵B（0x384-0x3c3）= rsi 矩阵复制。
- **0x1400D4200-0x1400D43C5**：0xc8+0x8f0 = **0x30 × (0x38 × 0x40)**：
  - 0x930-0x960 = 0x38 × 0x40（rdx=0x38 行 × rax=0x40 列）
  - 0x8f0-0x920 = 0x30 × (0x930-0x960)（rax=0xc8+0x30 矩阵）
- **渲染压栈**（0x1401EC8C2-0x1401EC993、0x1401E9836-0x1401E989E）：0x38 栈顶 ← 0x1160 矩阵、0x40 栈顶 ← 0x11a0 矩阵。**0x30 = 对象世界矩阵**（0x1401EC799 单位阵 或 0x1401EC878 从 rdi 复制）。
- **0x1160/0x11a0 相机矩阵缓存**（0x1401800B8-0x1401800FD）：0x1170-0x11a0 ← rsi+0x48 矩阵（4 行）、0x11b0-0x11e0 ← rsi+0x50 矩阵（4 行）。
- **0x14017FCFC-0x1401816CC** 大函数构造相机矩阵（0x14005F5B0 多次调用 edx=0..3，0.5 常量 0x1404926C0 出现）。0x14005F5B0-0x14005F5F3 为矩阵 helper。

### 官方数学结构（综合）
**定位矩阵 = origin×0.5×M，M = 0x30(世界) × 0x38(view?) × 0x40(proj?)，0.5 固定常量**
- 0.5 = 场景→画布缩放（官方画布=场景/2=1920）
- 若 0x38=视图（lookAt 含 T(-eye)），M 含 -eye 平移（360,269.56）×0.5 = (180,134.78) @1920 → 与用户最初"头相对背景偏移 100px+"（182px）吻合
- **puppet 特有**：origin（0x2f0，对象矩阵数组 0x210-0x2ff 的槽）被骨骼矩阵链乘法变换（0x140147F31 读、0x140147FC4 写回），image 无此路径 → **puppet 与 image 定位差异来源**
- DSH 对 puppet 用蒙皮后包围盒角（origin+minX）定位，官方用骨骼链变换后的 origin×0.5×M

## sf27 实现记录（视图平移 T(-eye)）

### 已实现（基于逆向确认）
- **官方 view 矩阵含 T(-eye) 平移**：0x1401EC720 渲染提交对所有对象压栈 0x1160/0x11a0（view/proj 缓存，从 rsi+0x48/0x50 复制）；0x14017FCFC 构造相机矩阵（0.5 常量参与）。
- **背景跳过视图**：0x304 的 0x1100 标志区分背景路径（用户最初"头相对背景偏移 182px@1920 = eye.x×0.5 = 360×0.5"证实背景不经 -eye）。
- **DSH 实现**：`_viewShift()` = 前景 (-camEye)×ps = (+360,+269.6) @3840，背景（size 达场景尺寸）返回 [0,0]。应用于 renderImage/renderPuppet/SolidLayer/TextObject。
- **验证**：amiya-sf27-verify.mjs 确认背景 314 shift=0，前景全部 +360,+269.6；sf27-diff 确认 31.3% 采样像素变化。
- 缓存键 sf20_ → sf27_；帧 scripts/out/amiya_sf27_3840.png（1.88MB，内容完整）。

### 未实现（缺失事实 → 待逆向）
