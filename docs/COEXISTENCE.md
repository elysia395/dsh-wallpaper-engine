## 现状四句话

1. **关壁纸、留玻璃：今天就支持** —— 当前壁纸卡片 →「关闭」。玻璃不受影响（有守卫钉着这条）。
2. **关玻璃、留壁纸：还没有总开关** —— 玻璃是「每面各关各的」（侧栏 / 思考块 / 左侧栏各有总开关）；
   页面级的令牌配方（对话框、面板、抬高按钮的底色）挂在页面玻璃锚点上常在，单面开关不管它。
   补上这个总开关的决策与前提见 [`adr/0010`](./adr/0010-glass-off-revisit-four-states.md)。
3. **皮肤中心接管时会自动让路** —— 检测到皮肤中心的公开标记（`html[data-dsh-skin]`）时，
   本插件自动清壁纸、整族摘掉玻璃门控、停轮换；对方持续离场后自动恢复。
   这是目前**唯一**的跨插件协商通道，方向是单向的（我们让路，别人无法让我们让路）。
4. **按宿主规范上色的第三方插件会「继承」我们的玻璃** —— DSH 给插件作者的规范是
   「用 `--dsw-alias-*` 设计令牌上色」，而这些令牌在玻璃生效时被改写成玻璃配方 ⇒
   任何按规范写的插件都会自动带上玻璃质感，**我们关不掉它、对方作者也不知道**。
   这是已知现状：账本与止损线（无门控改写的封闭白名单）见 [`TOKEN-CONTRACT.md`](./TOKEN-CONTRACT.md)。

## 冲突矩阵：症状 → 嫌疑机制 → 三步自查

| 症状 | 嫌疑机制 | 三步自查 |
|---|---|---|
| 装了某个 UI 插件后，它的面板 / 按钮变成玻璃质感或半透明 | **令牌层接管** —— 它按规范读 `--dsw-alias-*`，拿到的是玻璃配方 | ① 关掉壁纸看是否依旧（依旧 ⇒ 是令牌层，与壁纸无关）② 到 [`TOKEN-CONTRACT.md`](./TOKEN-CONTRACT.md) 查那个令牌挂在哪个门控下 ③ 关掉对应的玻璃面，看它是否随之退场 |
| 按钮 / 弹层错位、整块掉位 | **包含块劫持** —— 非 `none` 的 `backdrop-filter` 或 `transform` 会让祖先成为后代 `position: fixed` 元素的包含块 | ① DevTools 里看错位元素的定位祖先是不是我们的玻璃载体 ② 关掉对应玻璃面的模糊看是否恢复 ③ 回忆新装的插件是否往卡片里塞了 fixed 座位 |
| 一开皮肤中心画面就变、关掉后不恢复 | **让路协议** —— 检测到皮肤标记即清壁纸 + 摘玻璃门控，对方持续离场才恢复 | ① 关掉皮肤中心等几秒 ② 还不恢复就刷新页面 ③ 反复复现请带上诊断反馈 |
| 设置页跟别人的不一样（侧栏玻璃那节时有时无） | **配置面随插件组合变形** —— 那整节只在装了 `dsh-better-sidebar` 时渲染 | ① 确认本机是否装了侧栏插件 ② 装 / 卸各看一次即可复现 ③ 这是按已装插件裁剪，不是缺失 |
| 给终端插件设的字体没生效 | **跨插件投递接缝** —— xterm 只在构造那一刻读一次字体，钩子名或读取位置一变就静默失效 | ① 重启那个终端插件再看 ② 诊断里查字体相关行 ③ 反馈时带上插件名与版本 |

> 自我诊断的「共存」节与属性级 opt-out 在计划中（[`adr/0010`](./adr/0010-glass-off-revisit-four-states.md) 的 D3）——
> 落地前请按上表手动自查。

## 「关不掉玻璃」的真相

- 「关某一面得到的是半玻璃 ⇒ 整层退役、恒吃玻璃」这个结论（[`adr/0008`](./adr/0008-glass-config-two-state.md)）的
  前提是**令牌层有一批不挂门控的改写**；按复算结果这个前提**已不成立**
  （[`adr/0010`](./adr/0010-glass-off-revisit-four-states.md) 据此修订）：不挂门控的改写只剩**封闭白名单**
  （`body[data-we-thinking-native]` 思考块自己的开关、`.we-layer` 插件自有元素），
  「令牌层整组回退」已经成立 —— 缺的是一个主开关与一批守卫改写，不是架构。
- 所以今天**「关某个玻璃面」**的实际效果是：插件直接画在该面上的毛玻璃 / 模糊整组退场；
  而**令牌级配方挂在页面玻璃锚点上**，不归单面开关管 —— 按规范读令牌的面仍然会拿到玻璃配方。
  这就是「半玻璃」，也正是四态里的 `wallpaper-only` 要解决的问题。

## 共存四态（目标形态；后两态按 [`adr/0010`](./adr/0010-glass-off-revisit-four-states.md) 分批落地）

| 模式 | 玻璃釉层 | 页面透出壁纸 | 今天 |
|---|---|---|---|
| `full` 玻璃 + 壁纸 | 开 | 开 | ✅ 默认 |
| `glass-only` 只留玻璃 | 开 | 关 | ✅ 现在就支持（关掉壁纸即可） |
| `wallpaper-only` 只留壁纸 | 关 | 开 | ❌ 还缺主开关（渲染层已就绪，见 ADR-0010） |
| `off` 都关（让路态） | 关 | 关 | ⚙️ 内部已有（皮肤中心让路路径），待升格为可声明状态 |

> 想马上「只看壁纸不看玻璃」：目前只能逐面关（侧栏 / 思考块 / 左侧栏的总开关），
> 页面级令牌配方关不掉 —— 这正是待落地的 `wallpaper-only`。
