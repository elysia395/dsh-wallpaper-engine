# ADR-0015：玻璃表面所有权与层叠隔离（Surface Ownership）

- **Date**: 2026-10-17
- **Status**: Accepted
- **Deciders**: 用户批准统一表面层设计
- **Amends**: ADR-0008、ADR-0010 中有关背景令牌向所有插件泛化的实现选择；总开关规划不由本决策代替

## Context

旧架构同时依赖全局背景令牌、私有类名补丁和目标本体滤镜。设置窗口透明并不意味着内部插件背景适配；为侧栏添加定位与层叠上下文还会困住第三方模态。背景修补与字体修补不能解决这类所有权和层叠问题。

证据入口为 `src/styles/base.js`、`src/styles/chrome.js` 的旧绘制路径（第三处 `src/styles-sidebar.js` 已删除，不再可作入口），行为复现由 `test/verify-glass-runtime-browser.mjs` 维护。保留旧决策正文作为历史，不将历史约束解释为本轮禁止回退原生的要求。

## Decision

### D1：先判定所有权，再绘制

统一运行管理器将参数解析、载体资格与生命周期分开。已知宿主表面及显式声明面才具备适配资格；未知内容保留原生，不按私有类名猜测内部布局。策略回退和 preserve 声明优先于自动接管。

### D2：装饰不得改变共享内容的层叠结构

模糊只放在独立装饰叶节点或表面已有上下文中的空闲伪元素上。不为宿主共享祖先增加定位、滤镜或层叠上下文，不移动第三方节点，不通过提高层级或借 top layer 赢得遮挡冲突。无法证明几何安全就回退原生。

### D3：限定背景配方的作用域

设置和声明面直接绘制所拥有的基底，只清已声明的布局背景。已知编辑画布保留语法与选区语义。壁纸让开规则只识别外层宿主壳，不按通用类名清理任意子树。

**修正（2026-10-18，用户实测）**：页面级背景层令牌映射（`--dsw-alias-bg-layer-*` / `--dsw-alias-button-elevated-fill` / `--dsw-alias-bg-overlay` …）必须作用在 `body[data-we-glass-page]` 的**整页**上，不能收窄到聊天流。这族令牌是宿主自己的侧栏按钮、右栏页签栏与设置窗卡片的底色来源；收窄后它们全部退回宿主实底（用户原话：「这些我用红色矩形框选中的组件的玻璃效果又丢失了」）。每条映射仍带可读性下限，因此不违反"不做无下限透明"；被改写的只是**底色**，按钮语义色、语法色与 ANSI 色保持原生。
同理，设置窗的表面令牌必须声明在**对话框本体**上而不是 `::before` 装饰叶：伪元素没有后代，声明在它上面的变量无人继承，窗内控件照样退回实底。会建立包含块的那几样（滤镜 / 底色 / 釉光 / 阴影）仍只写在装饰叶上，D2 不受影响。

### D4：退出必须可逆

每条认领记录管理自己创建的属性与装饰。目标消失、隐藏、策略变化、皮肤接管和卸载均撤回对应效果。观察器合并更新，静止时不持续扫描。外部模态在场时，本插件的装饰和自动提示让路，不改写对方层级。

**修正（2026-10-18，用户实测）**：D2 的"祖先链不安全就回退原生"有两处过宽，会把**短暂的布局过渡**误判成不安全 —— 宿主开合右栏时在 `AppFrame` 上做 `transition: grid-template-columns`，而 frame 是左右两侧栏共同的祖先，于是动画那 300ms 里两侧玻璃同时消失、结束后才回来（用户原话：「侧边栏弹出时会出现丢失左右两侧的玻璃效果…只出现在过程中」）。现口径：
· **有限**的动画 / 过渡 ⇒ 继续接管，并逐帧重算载体矩形（`state.moving` + rAF 跟随，静止即停，另有帧数上限兜底）；
· 正在做 transform 动画的元素 ⇒ 不是"静态 transform"，可以放行（几何由跟随循环保证）；
· **无限**动画（常驻 spinner 一类）不触发跟随 —— 否则等于常驻 rAF；
· 无动画的静态 transform / filter / 隔离上下文仍一律回退原生（守卫保留该负对照）。

### D5：逐面策略不替代参数模式

`glassSurfacePolicy` 管接管资格，`glassMode` 保留继承 / 独立参数语义。策略走共享 schema 和已有预设链，不另建不一致的存储格式。高级状态只展示所有权原因，不采集宿主文本。

## Consequences

未知插件可能保留实底，视觉上不追求所有窗口都透明。这是保持内容、控件语义和弹层正确性的代价。显式接入也必须通过安全检查，不能承诺未来所有宿主结构自动兼容。

旧静态守卫需从历史 CSS 形状迁移到所有权与实际行为，不能删掉可读性或负对照。浏览器回归使用真实 bundle，但隔离夹具不是所有插件实装验收；独立审查和未测平台仍须单列。

## 重新考虑的触发线

宿主提供稳定的材质 / 层叠协议，或当前载体资格导致常见安全表面持续退回原生时，可以新增适配器或替换绘制后端。不得以扩大通配选择器、全局透明或提高层级作为兼容捷径。
