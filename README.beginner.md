# dsh-wallpaper-engine 小白上手版

[专业中文版](README.md) | [English (developers)](README.en.md) | [小白上手版](README.beginner.md)

> 这份文档给**完全不懂代码**的朋友准备。跟着做就行，不要求你懂任何技术名词。

## 这是什么？

简单说：装了它之后，你 **Wallpaper Engine（壁纸引擎）里下载好的壁纸**，会出现在 **DSH 的网页聊天界面**后面当背景，还自带一层苹果风格的「毛玻璃」效果。

- 视频壁纸 → 直接在网页里播放；
- 网页壁纸 → 加载进来动起来；
- 场景壁纸（3D 那种）→ 显示它的静态画面（没法动，但能看）；
- 还可以上传你自己的图片 / 视频当壁纸。

![效果示意](https://raw.githubusercontent.com/elysia395/dsh-wallpaper-engine/main/docs/images/showcase.png)

## 开始前，请确认你有：

| 需要 | 说明 |
|---|---|
| Windows 电脑 | 本插件只支持 Windows（macOS 另有版本，见文末） |
| 安装了 DSH | 也就是你平时打开网页聊天界面的那个东西 |
| 安装了 Wallpaper Engine | Steam 里的壁纸引擎，且**已经下载过至少一张壁纸** |
| 不需要会编程 | 整个过程就是复制一行命令、点几下鼠标 |

> 壁纸引擎**不用打开**，插件是直接读你硬盘上的壁纸文件。

## 第一步：安装（只需 1 条命令）

1. 打开电脑的「**终端 / 命令行**」：
   - 按键盘 `Win + R`，输入 `powershell`，回车；
   - 或者开始菜单里搜「PowerShell」打开。
2. 把下面这一行**完整复制**，粘贴进去，按回车：

```
dsh plugin --profile web add dsh-plugin-wallpaper-engine
```

3. 等它显示完成后，**重启 dsh**（把 `dsh web` 关掉再打开）。

> ❓「终端是什么？」——就是一个黑底白字、用来输入命令的小窗口。你只需要复制粘贴，不用理解命令是什么意思。

## 第二步：打开插件设置

1. 打开 DSH 的网页界面（`dsh web`）。
2. 点右上角 **设置**。
3. 在左边导航里找到 **Wallpaper Engine**，点它。

如果左边**没有**这个入口，说明第一步没装成功——回去重新执行那条命令，或者看下面的「常见问题」。

## 第三步：选一张壁纸

1. 在 Wallpaper Engine 设置页里，点 **选择壁纸**。
2. 弹出的小窗口里会列出你的壁纸缩略图，**点任意一张**，它立刻出现在聊天界面后面。
3. 按键盘 `ESC`，或点窗口外面，关掉选择框。

搞定 ✅。选择会被记住，下次打开还在。

## 常用功能（都在设置页里）

| 你想干嘛 | 怎么操作 |
|---|---|
| 换一张 | 选择壁纸 → 点另一张 |
| 关掉壁纸 | 点 **关闭** 按钮，或在选择框里点「✕ 关闭」卡片 |
| 暂停视频壁纸 | 点 **暂停**（再点恢复播放） |
| 视频太快/太慢 | 「壁纸效果」区的 **倍速** 按钮 |
| 画面左右反过来 | 打开 **水平翻转** 开关 |
| 背景太亮看不清字 | 把 **暗化** 拉高；还不够就把 **边框** 也拉高 |
| 想让背景模糊一点 | **壁纸模糊** 拉高 |
| 界面太透/太实 | **玻璃透明度** 滑动条 |
| 换个主题色 | 「外观」区的 **配色** 圆点 |
| 不想看到某张壁纸 | 点它右上角的 **隐藏**（不会删文件，能在「已隐藏」里恢复） |
| 用我自己的图片/视频 | 「自定义壁纸」区上传 JPG / PNG / MP4 |
| 每隔一段时间自动换 | 「轮播列表」区新建列表 → 勾上 **自动轮转** |

> 💡 浅色 / 深色主题下同一张壁纸效果可能差别很大，两种都试试，选顺眼的。

## 常见问题

### 1. 设置里没有 Wallpaper Engine 这一项

- 检查第一步的命令有没有报错；
- 确认装完后**重启过** dsh；
- 确认电脑上装了 Steam 版 Wallpaper Engine。

### 2. 有入口，但选择框里是空的

- 你的壁纸引擎里还没有下载壁纸，先去 Steam 的壁纸引擎工坊订阅几张；
- 点 **刷新** 按钮重扫一次。

### 3. 场景壁纸只显示了一张静态图 / 预览图

这是**正常现象**。场景壁纸是 3D 的，网页里放不了 3D，插件会提取它的主画面当静态背景；个别提取不出来的会自动显示官方预览图。

### 4. 网页壁纸（Web 类型）动得不对 / 部分交互没反应

为了安全，网页壁纸在受限的「沙箱」里运行：画面动画正常，但个别需要读取网页数据的交互功能可能受限。这是有意为之。

### 5. 壁纸文件想换到别的盘存（不想占 C 盘）

设置页「自定义壁纸」→ **存储位置** → 点 **更改**，输入你想放的位置（比如 `D:\MyWallpapers`），点保存。已有文件会自动搬过去。万一有文件因为被占用或权限问题没能搬过去，页面会提示你「N 个文件未能迁移」，去旧目录手动处理即可。

### 6. 装了插件但想卸载

打开 **设置 → 插件**，找到本插件并移除（不同版本界面位置可能略有差别）；卸载前建议先在 Wallpaper Engine 设置页点 **关闭** 停用壁纸。

### 7. 我是 macOS 用户

Wallpaper Engine 本身没有 Mac 版。Mac 用户可以安装社区维护的另一个包：

```
dsh plugin --profile web add dsh-plugin-wallpaper-engine-mac
```
